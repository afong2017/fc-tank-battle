# FC Tank Battle

一个用 Canvas/Web Audio/Gamepad API 做的 FC 风格坦克大战复刻小游戏。

## 运行

直接用浏览器打开 `index.html`。

## 操作

- 1P 键盘：方向键 / WASD 移动，Space 开火，Enter 开始，P 暂停
- 2P 键盘：IJKL 移动，U 开火
- Xbox 手柄：左摇杆 / 方向键移动，A / RB 开火，Start 开始或暂停
- 任意时候：按 Xbox Back 呼出选关菜单；手柄菜单里摇杆左右切换项目，上下调整关卡和生命值，A 确认并跳到下一项，最后一项 A 开始，Start 可直接开始；键盘可用方向键、数字键、PageUp/PageDown，鼠标可点击/滚轮调整
- 调整关卡时，画布会实时显示当前选中关卡的地图预览
- 无人操作：2P 默认由 AI 托管，1P 3 秒无人操作后由 AI 托管，人工输入会接回 1P
- 开始前可设置 1P/2P 生命数：3 到 100 或无限
- 友方火力会造成伤害，AI 会尽量避免朝队友所在射线开火
- 右侧面板会实时显示 1P / 2P 阵亡次数，以及击毁坦克总数、普通、快速、装甲分类数量

## 内容

- 三十五张 26x24 像素网格关卡，按 FC《坦克大战》风格重绘，中路采用分段障碍和错位通道，会循环推进
- 通关 35 关后回到第 1 关，第二轮起敌人数量、速度、开火频率和生成速度会逐步提高
- 砖墙、钢墙、水、树林、基地
- 普通、快速、装甲敌方坦克
- 爆炸、射击、命中、奖励音效
- 星星强化和冰冻奖励
- AI 会在后台继续运行，并通过本地学习记忆调整守家、进攻、支援和避弹策略；会实时扫描全图，优先保护老巢、自己和队友，锁定高威胁目标、守点伏击、清理障碍，并在确认射线可命中后再停住瞄准开火
- AI 会避免射击老巢核心、老巢护墙区域和队友所在射线

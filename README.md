# FC Tank Battle

一个用 Canvas/Web Audio/Gamepad API 做的 FC 风格坦克大战复刻小游戏。

## 运行

直接用浏览器打开 `index.html`。

## 操作

- 1P 键盘：方向键 / WASD 移动，Space 开火，Enter 开始，P 暂停
- 2P 键盘：IJKL 移动，U 开火
- Xbox 手柄：左摇杆 / 方向键移动，A / RB 开火，Start 开始或暂停
- 无人操作：2P 默认由 AI 托管，1P 10 秒无人操作后由 AI 托管，人工输入会接回 1P
- 开始前可设置 1P/2P 生命数：3、5、10 或无限

## 内容

- 两张 26x24 像素网格关卡，会循环推进
- 砖墙、钢墙、水、树林、基地
- 普通、快速、装甲敌方坦克
- 爆炸、射击、命中、奖励音效
- 星星强化和冰冻奖励
- AI 会在后台继续运行，并通过本地学习记忆调整守家、进攻、支援和避弹策略
- AI 会避免射击老巢核心、老巢护墙区域和队友所在射线
